# 💊 VKR Backend API (Medicine Tracker)

Это серверная часть (REST API) для приложения "Умная аптечка" — дипломного проекта (ВКР), предназначенного для управления домашними медикаментами и контроля за курсами лечения.

## 🚀 Основные возможности
* **Семейные профили:** Управление курсами лечения для разных членов семьи.
* **Общие аптечки:** Возможность делиться доступом к аптечке (роли: `owner`, `editor`, `viewer`).
* **Точный учет остатков:** Автоматическое списание лекарств из физических упаковок при логировании приема.
* **Гибкие расписания:** Поддержка сложных курсов (интервальные, по дням недели, ежедневные, по потребности).
* **Система уведомлений:** Трекинг просрочки (за 30 дней, за 7 дней) и напоминания о приеме.
* **Офлайн-first:** Поддержка `client_created_at` для бесшовной офлайн-синхронизации с мобильным клиентом.

## 🛠 Технологический стек
* **PHP:** 8.4
* **Framework:** Laravel 11
* **Database:** PostgreSQL 16
* **Environment:** Docker (docker-compose)

## 📦 Развертывание локально

1. Склонируйте репозиторий:
   ```bash
   git clone <your-repo-url>
   cd backend
   ```
2. Установите зависимости:
   ```bash
   composer install
   ```
3. Настройте файл окружения:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
4. Поднимите базу данных в Docker:
   ```bash
   docker-compose up -d
   ```
5. Запустите миграции:
   ```bash
   php artisan migrate
   ```
6. Запустите локальный сервер:
   ```bash
   php artisan serve
   ```

## 🗄 Структура Базы Данных
Архитектура базы данных спроектирована с учетом строгой ссылочной целостности (каскадное удаление, restrict-якоря). Схема включает таблицы:
`users`, `profiles`, `medicine_boxes`, `medicine_box_users`, `reference_medicines`, `medicines`, `intake_courses`, `intake_schedules`, `intake_logs`, `notification_logs`.
